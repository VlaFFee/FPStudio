# FP Studio — студия анимаций от первого лица (Minecraft 1.20.1, Forge 47.x)

Клиентский мод: в **креативе** создаёшь кинематографичные анимации рук и камеры от первого лица
(как в синематиках), с настоящим взаимодействием с миром. Серверу мод не нужен, работает на ванильных серверах.

## Сборка через GitHub (без установки чего-либо)
1. Создай репозиторий на GitHub и загрузи в него **содержимое** этой папки (чтобы `build.gradle` лежал в корне, а не в подпапке).
2. Открой вкладку **Actions**. Сборка запустится сама после загрузки; её можно запустить вручную: *Build mod → Run workflow*.
3. Когда появится зелёная галочка, открой запуск и внизу в **Artifacts** скачай `fpstudio-mod`. Внутри лежит `fpstudio-1.0.0.jar`, его кладёшь в папку `mods` (нужны Minecraft 1.20.1 и Forge 47.x).
4. Хочешь готовый файл в Releases: создай тег `v1.0.0` (`git tag v1.0.0 && git push --tags`).

Если сборка красная, открой лог шага **Build** и пришли мне текст ошибки.

## Сборка на своём компьютере
Нужны JDK 17 и интернет (Forge / Mojang / Maven).
```
gradle wrapper --gradle-version 8.8     # один раз, если нет gradlew (или открой папку в IntelliJ IDEA)
./gradlew runClient                      # запуск игры для проверки
./gradlew build                          # jar: build/libs/fpstudio-1.0.0.jar -> в папку mods
```

## Управление
| Действие | Как |
|---|---|
| Открыть студию | **O** (или `/fpstudio`) |
| Играть / стоп текущий клип | **P** (или `/fpstudio play <имя>`, `/fpstudio stop`, `/fpstudio list`) |
| Пуск/пауза в студии | Пробел |
| Шаблон движения (вкладка «Шаблоны») | клик по шаблону, вставляется на ползунок или в конец клипа |
| Запись мышью | **E**: двигайте мышью (Shift — вращение), колесо — вперёд/назад, ещё раз E — стоп |
| Размер интерфейса | кнопки **-/+** сверху или Ctrl +/- |
| Новый ключ | **K** (на выбранной строке) или двойной клик по строке |
| Двигать руку мышью | удерживай **G** (+**R** — вращать, колесо — вперёд/назад) |
| Полноэкранный просмотр с событиями | **Enter** |
| Отмена / повтор / сохранить | Ctrl+Z / Ctrl+Y / Ctrl+S |
| Масштаб / прокрутка таймлайна | Ctrl+колесо / СКМ |
| Полосы сверху и снизу | кнопка **«Полосы»** или **B**; соотношение — вкладка «Клип» |
| Дорожки ↔ кривые | кнопка **«Кривые/Дорожки»** или **Q** |

## Ввод чисел вручную
У каждого ползунка справа есть рамка со значением: кликните по ней и впишите любое число (Enter — применить, Esc — отмена, запятая тоже подходит). Значение не ограничено диапазоном ползунка, поэтому можно задать длительность, позицию или поворот куда больше обычного.

## Таймлайн (как в редакторах анимации)
* **Дорожки**: у каждой дорожки (правая рука, левая рука, камера) раскрывается список каналов (X, Y, Z, наклон, поворот, крен, FOV). Ключ можно поставить на один канал: двойной клик по строке канала — ключ только на нём, по строке дорожки — на всех.
* **Выделение**: рамкой по пустому месту, Shift/Ctrl — добавить/убрать, Ctrl+A — всё. Выделенные ключи таскаются вместе (Shift — без привязки к сетке 0.05 с). Alt+←/→ сдвигает их на кадр.
* **Кривые** (кнопка «Кривые» или Q): график выбранной дорожки; ключи тащатся и по времени, и по значению. Колесо — масштаб по вертикали, Ctrl+колесо — по времени, F — вписать, СКМ — двигать вид. Клик по названию канала включает/скрывает кривую.
* **ПКМ по ключу**: интерполяция (плавность) для всех выделенных, дублировать, копировать, удалить. **ПКМ по пустому месту**: добавить ключ, вставить, выбрать всё.
* **Ctrl+C / V / D**: копирование, вставка в позицию курсора, дубль со сдвигом.
* Высоту таймлайна можно менять, потянув за его верхнюю границу.
* Ползунки справа правят ключ; канал, которого в ключе нет, показан тусклым — при изменении он становится ключом.

## Полосы сверху и снизу
Кнопка **«Полосы»** (или **B**) включает и выключает чёрные кинополосы клипа. Они видны сразу — и в студии, и при игре, и в режиме «в мир». Соотношение сторон задаётся ползунком «Соотношение полос» на вкладке «Клип» (по умолчанию 2.39).

## НПС из Blockbench (GeckoLib)
1. В Blockbench сделайте модель (формат **Bedrock / GeckoLib**), экспортируйте `ИМЯ.geo.json`, скин `.png` и `animation.json` (File → Export).
2. Положите файлы в `config/fpstudio/npcs/ИМЯ/` (или россыпью: `ИМЯ.geo.json`, `ИМЯ.png`, `ИМЯ.animation.json`). При первом запуске там уже лежит пример `robot`.
3. В студии откройте вкладку **«НПС»** → **«Обновить»** → нажмите **«+ ИМЯ»**: НПС появится перед вами лицом к вам. Это клиентский «актёр»: его видите только вы (для съёмки), сервер и GeckoLib не нужны.
4. В списке **«Анимации»** все анимации из animation.json: клик ставит анимацию на таймлайн в позицию курсора и проигрывает её. Событие «НПС: анимация» можно двигать, копировать, менять анимацию и скорость; длительность 0 — играет до следующей анимации этого НПС. Между анимациями плавный переход.
5. **Правка анимаций в игре**: клик по кости в списке «Кости» открывает её дорожку (позиция, поворот, масштаб). Ключи добавляются поверх играющей анимации. Дорожка «Движение» двигает и поворачивает всего НПС (идти, подойти к игроку).
6. Событие **«НПС: взгляд камеры»** плавно поворачивает вашу камеру на НПС или его кость. Вместе с руками, камерой и полосами получается полноценная сцена.
Положения, размер, простой (idle) настраиваются на вкладке «НПС».

**Части тела**: рядом с каждой костью кнопка `*` — спрятать/показать часть (ЛКМ — вместе со всем, что к ней прикреплено, ПКМ — только эту кость). Выбранная кость подсвечивается в мире, есть поиск по названию. G + мышь вращает выбранную кость, G + Shift двигает. Скрытие хранится в клипе.

## Убрать руки на время
Кнопка **«Руки»** (или **H**) ставит на позицию курсора событие: если руки в кадре, они плавно уедут вниз за экран, если спрятаны — вернутся. Нажмите ещё раз позже в той же анимации, чтобы вернуть. Событие «Руки: убрать/вернуть» можно двигать по таймлайну, менять (какие руки: обе/правая/левая, убрать или вернуть) и задавать время плавности. **Направление**: «Куда» — куда руки уедут (вниз, вверх, в сторону наружу, к центру, вперёд или «свой вариант»), «Откуда» (у события «вернуть») — откуда они выедут: «как ушли» или любое другое. В «своём варианте» вы сами задаёте смещение X/Y/Z и наклон/крен (числа можно вписывать, значения для правой руки, левая зеркалится). Так можно, например, убрать руки вниз, а вернуть сверху или сбоку.
Предмет в руке уезжает вместе с рукой. В дорожке «События» они видны как ромбики. Кнопка «Убрать / вернуть руки» также есть на вкладке «Клип».

## Запись движения игрока в мире
Кнопка **«● Ходьба»** (или **R**) в студии: студия закрывается, идёт отсчёт 3 секунды (встаньте на стартовую точку), потом запускается анимация (руки и НПС играют как обычно) и **записывается всё, что вы делаете**: куда идёте и куда смотрите. Закончить: **O** или **P**; клип сам удлиняется, если вы идёте дольше. Способ записи выбирается на вкладке «Клип»:
* **Камерой (по умолчанию)**: ваш путь и взгляд становятся **ключами дорожки «Камера»**. С ними всё как с обычной камерой: двигать, менять ракурс ползунками и вводом чисел, плавность, кривые, копировать, добавлять свои ключи.
  * **Привязка к месту записи**: камера «приклеена» к точке мира, где началась запись, и идёт от неё, где бы вы ни стояли. Перед стартом она плавно пролетает из вашего вида в эту точку (**«Пролёт в начало»**, по умолчанию 1.2 с, время клипа в это время не идёт), в конце так же плавно возвращается (**«Пролёт обратно»**).
  * **Сглаживание** (вкладка «Клип», блок «Камера»): ползунок «Сглаживание (сек)» (0 — как записано, 0.3–0.6 — плавно, 1+ — очень мягко) и «Точность ключей». Сырая запись хранится в клипе, поэтому сглаживание можно менять сколько угодно: поставьте значения и нажмите **«Применить к записи»**. После записи студия сама открывается на этой вкладке. «Сгладить текущие ключи камеры» сглаживает ключи и после ваших ручных правок.
  * При проигрывании игрок стоит на месте, камера летит по записи. Во время записи ваша старая камера отключена.
* **Событиями**: путь превращается в события «Идти», «Бежать», «Красться», «Прыжок», «Повернуться», и игрок при проигрывании реально идёт по миру. Для этого начинайте проигрывание с той же точки и взгляда.
Старые ключи камеры (или события движения) внутри записанного отрезка заменяются, результат можно отменить через Ctrl+Z.

## Как быстро сделать анимацию
1. Вкладка **Шаблоны**: «Потянуться», «Удар», «Поставить блок», «Помахать», «Толкнуть», «Показать предмет» и др. Один клик вставляет движение, и оно сразу проигрывается. Шаблоны можно ставить подряд.
2. Или нажмите **E** и просто водите мышью: руки или камера записываются сами, лишние ключи убираются автоматически.
3. Точная подгонка: выберите ключ и поправьте ползунки, либо G + мышь.

## Ходить по миру и двигаться в кадре
* **Tab / «Выйти в мир»**: студия закрывается, но руки и камера остаются живыми. Можно ходить, смотреть по сторонам, целиться, потом нажать **O** и вернуться.
* **События движения** на дорожке «События» (у них есть длительность): *Идти*, *Бежать*, *Красться*, *Прыжок*, *Повернуться*. Игрок реально идёт и поворачивается, поэтому «ударить/использовать» попадает туда, куда он уже повернулся.
* Для проверки прямо из студии включите **«Живой тест»**, либо играйте полноэкранно (**Enter** или **P**).

## Удобство
Ctrl+Z/Ctrl+Y откатывают только данные — выбранный ключ и панель остаются на месте. В полях ввода работают Ctrl+C/X/V/A. Наведи мышь на любой ползунок с числом: Ctrl+C копирует значение, Ctrl+V вставляет в другой ползунок.

## НПС в мире (как у сюжетных сборок)

Теперь НПС — **настоящие сущности**: ходят по миру, смотрят на игрока, идут по маршруту, выполняют скрипты, пишут в чат, запускают ваши клипы-катсцены. Мод должен стоять **и на клиенте, и на сервере** (в одиночной игре — просто в папке mods).

**Модели.** Папка `config/fpstudio/npcs/ИМЯ/` с `ИМЯ.geo.json`, `*.animation.json` и скином `.png` (экспорт из Blockbench / GeckoLib). Файлы моделей должны быть у каждого игрока (рендер идёт на клиенте); серверу они нужны только чтобы знать длину анимаций для `animwait`.

**Создать / править.**
- Клавиша **N** (настраивается): смотрите на НПС или встаньте рядом (до 6 блоков) — откроется редактор; иначе — окно «Новый НПС» (создаётся там, куда вы смотрите; **Shift+N** — всегда новый).
- Или Shift+ПКМ по НПС (креатив / оператор).
- Команды: `/fpnpc spawn <модель> [имя]`, `/fpnpc edit|run|stop|remove <НПС>`, `/fpnpc list`, `/fpnpc var <имя> <значение>` (общая переменная `g.имя`).

**Редактор** — 4 вкладки: *Основное* (модель, имя, размер, скорость, неуязвим/толкается, взгляд, прогулка в радиусе, предметы в руках), *Анимации* (какая анимация для «стоит / идёт / бежит / говорит / сидит», тест-проигрывание, кнопка «Править в студии»), *Маршрут* (точки, ожидание, скрипт на точке, режимы: по кругу / туда-обратно / один раз), *Скрипты*.

**Править готовую анимацию.** Вкладка «Анимации» → «Править эту анимацию в студии»: откроется студия со сценой, где НПС играет выбранную анимацию. Двигайте кости и ставьте ключи (вкладка НПС → кость), затем кнопка **«Экспорт в анимацию НПС»** — правки запекаются в новую анимацию `имя_edit` в `edited.animation.json` рядом с моделью (обычный формат Blockbench, оригинал не трогается). Выберите её в списках анимаций НПС.

**События-скрипты:** `on_spawn`, `on_interact` (ПКМ), `on_near` (игрок подошёл), `on_hurt`, `on_death`, `on_route_end`, а также любые свои имена (вызов `call имя`, на точке маршрута, кнопка «Запуск», `/fpnpc run`).

**Команды скрипта** (по строке, `#` — комментарий; в тексте `{player}`, `{npc}`, `{x}{y}{z}`, `{переменная}`, цвета `&6`):

| команда | что делает |
|---|---|
| `say текст` / `saywait` / `whisper` | сказать в чат (рядом / и подождать / только игроку) |
| `title`, `actionbar` | надпись игроку |
| `wait 2`, `waitinteract`, `waitnear 3` | пауза, ждать ПКМ, ждать приближения |
| `anim имя [loop]`, `animwait имя [сек]`, `stopanim` | анимация |
| `walk x y z [run]`, `walkto player`, `follow [дист] [run]`, `stop` | движение (`~` — относительные координаты) |
| `look player\|x y z\|off`, `turn угол`, `face` | взгляд и поворот |
| `sit`, `stand`, `tp x y z`, `tpplayer x y z` | поза и телепорт |
| `command /...` | команда от имени сервера (`{player}` подставится) |
| `give id [n]`, `take id [n]`, `sound id`, `equip слот id`, `setname` | предметы, звук, экипировка |
| `set имя знач`, `add имя [n]` | переменные (`g.имя` — общие на мир) |
| `if имя == знач goto метка`, `if hasitem id [n] / near 4 / day / night / sneaking goto метка` | условия (`!` — отрицание) |
| `label`, `goto`, `call`, `end` | ветвления |
| `cutscene имя` | запустить у игрока клип FP Studio (катсцена) |
| `dialog id`, `ext имя арги` | события Forge `NpcEvents.Dialogue` / `NpcEvents.Custom` для вашего мода диалогов |

Пример:
```
# on_interact
face
say Привет, {player}!
animwait wave
if has_key == 1 goto open
say Принеси ключ.
end
label open
say Заходи.
walk ~3 ~ ~
```

## Свой чат

Мод заменяет панель чата Minecraft (ввод и команды — как обычно). Сообщение — «плашка» с иконкой слева, цветным **[Именем]:** и текстом, с анимацией появления и затухания.

**Редактор:** клавиша **U**, команда `/fpchat` или шестерёнка ⚙ над строкой ввода чата.
- **Мини-экран справа** рисует настоящий чат. **Тяните чат мышью**, край рамки меняет ширину, колесо — масштаб, стрелки двигают на 1 px (Shift — на 5), Ctrl+Z / Ctrl+Y — отмена/возврат. Режим «Как в игре» показывает появление и затухание вживую.
- **Место:** пресеты («Как в кадре» — по центру снизу, «Классика», «Минимал», «Кино», «Справа сверху»), **сетка якорей 3×3** (чат прикрепляется к углу/краю/центру экрана), отступы от якоря, ширина, масштаб всего чата, отдельный размер текста, сколько сообщений показывать. После перетаскивания чат сам прилипает к ближайшему якорю (можно выключить).
- **Вид:** плашка / полоска / без фона, скругление, прозрачность и цвет фона, отступы, время сообщений, формат игроков `[Имя]: текст`.
- **Текст:** шрифт — из ресурспаков (`assets/<ns>/font/<имя>.json`; положите свой шрифт в ресурспак и выберите здесь, можно ввести id вручную), размер текста, цвета, тень.
- **Анимации:** появление (проявление, выезд снизу/сбоку, всплытие), длительность, дальность выезда, плавное смещение старых сообщений; затухание (проявление, уезжает, сжимается), сколько висит и как долго гаснет.
- **Иконки:** голова игрока для его сообщений, иконка по умолчанию, свои PNG из `config/fpstudio/chat_icons/` (формат: `имя_файла`, `player:Ник`, `item:minecraft:apple`).
- **Правила:** регулярное выражение по тексту → иконка, цвет `[Имени]` или скрыть сообщение.
- Каждое числовое поле — ползунок **и** окошко: в окошко можно вписать значение за пределами ползунка.
- **НПС в чате:** `say` показывает `[Имя НПС]: текст` с иконкой (поле «Иконка в чате» НПС, иначе `chat_icons/<модель>.png`), цвет имени — поле «Цвет имени в чате».
- Настройки в `config/fpstudio/chat.json`; чат — клиентская часть, у каждого игрока свой.

## Какие руки видны
Новые клипы начинаются **только с правой рукой**. Вкладка «Клип» → «Руки в кадре»: правая, левая, обе или никакие (клик листает вперёд, правый клик назад). Дальше обе руки анимируются как обычно, а «Руки: убрать/вернуть» на таймлайне работают поверх этого выбора. Старые клипы сохраняют свою настройку.

## Блокировка управления
Вкладка **Клип** в студии:
* **Блок. управления**: на время анимации этого клипа нельзя ходить, вертеть мышью, нажимать кнопки (в том числе инвентарь, чат, хотбар) и крутить колесо. Руки и камера остаются под анимацией, а движение из событий *Идти/Повернуться* продолжает работать.
* **Блок. во всех клипах**: то же самое для любой анимации (параметр `lockInputDuringAnimations` в `fpstudio-client.toml`).
* **Аварийный выход всегда доступен: Esc или P.** Блокировка действует только при полноэкранном воспроизведении (Enter или P), а не в окне студии.

## Шаблоны (29)
* **Базовые (14):** осмотреть руки, потянуться, удар, поставить/сломать блок, помахать, толкнуть, показать предмет, взмах, прикрыться, пропустить удар, посмотреть на руки, подобрать, поднести к лицу.
* **Эпичные (9):** появление рук, приземление героя, размашистый удар, комбо из трёх ударов, накопить силу и выпустить, закрыться от удара, пошатнуться, резкий разворот, долли-зум.
* **С движением игрока (6):** бег, рывок, медленный шаг, подойти и открыть дверь, запрыгнуть на выступ, осмотреться.

## Масштаб интерфейса
Размер студии = «Размер GUI» из настроек Minecraft (Настройки → Видео) × множитель мода (по умолчанию 75 %).
Множитель меняется кнопками -/+ в студии и хранится в `config/fpstudio-client.toml` (`uiScale`).

## Что умеет
* Дорожки: **правая рука**, **левая рука**, **камера** (позиция, углы, крен, FOV), **события**.
* Ключи с 10 типами плавности, включая сплайн (мягкая кривая через соседние ключи).
* Плавный вход/выход, «дыхание» рук, ручная дрожь камеры, удар камеры (IMPACT), кинополосы, скрытие HUD, заморозка ходьбы.
* События, работающие по-настоящему (через обычные пакеты игрока): взмах, ПКМ по прицелу (поставить блок, открыть дверь, использовать предмет),
  ЛКМ по прицелу (сломать блок, ударить моба), звук, смена слота.
* Предметы в руках отображаются как в ванили; пустая рука — рука со скином.
* Клипы хранятся в `config/fpstudio/clips/*.json`, при первом запуске создаются три демо-клипа.
* Конфиг `fpstudio-client.toml`: `requireCreative`, `studioFx`, `uiAnimationSpeed`.

## Важно
Мод написан без возможности скомпилировать против Forge (в среде разработки были закрыты репозитории). Логика модели данных
проверена тестами, остальной код проверен на синтаксис. Возможны мелкие правки сигнатур при первой сборке.

## Свои шрифты и звуки печати (без ресурспака)

При первом запуске создаются папки `config/fpstudio/chat_fonts` (шрифты `.ttf`/`.otf`) и `config/fpstudio/chat_sounds` (звуки `.ogg`, моно).
Положите файлы, откройте редактор чата (U) → «Шрифт» → «Применить шрифты и звуки» (или перезапустите игру). Мод сам собирает
ресурспак `resourcepacks/FPStudio_Assets` и включает его. Шрифт будет в списке как `fpstudio_user:имя_файла`, звук — `fpstudio_user:blip.имя_файла`.

## Печать как в Undertale / Deltarune

Редактор чата → вкладка «Печать»: включить «Плавная печать», скорость, паузы на знаках препинания. Звук печати: голос по умолчанию
(звук, громкость, тон, разброс, «каждые N букв», буквы без звука) и отдельный звук для букв: `aeiou=minecraft:block.note_block.pling@1.3; mnb=fpstudio_user:blip.low@0.8`.
«Голоса по шаблону» — у каждого персонажа свой писк (regex по тексту, например `^\[Санс\]`).

## GIF в чате и эффекты текста (как у Тенны / хоррор-эффекты)

* GIF кладите в `config/fpstudio/chat_gifs` (папка создаётся при первом запуске). В тексте: `<gif=имя>` или `<gif=имя,24>` (размер в пикселях),
  в иконку сообщения: `gif:имя` (например, в поле «Иконка в чате» у НПС или в правиле).
* Эффекты по участкам текста: `<shake>`, `<wave>`, `<glitch>`, `<flicker>`, `<blood>`, `<glow>`, `<ghost>`, `<corrupt>`, `<rainbow>`, `<robot>`, `<color=#FF8800>`.
  Параметры: `<shake=2>` (сила), `<glow=1,#7FD0FF>` (сила и цвет). Теги вкладываются, `</>` закрывает последний.
  Пример реплики НПС: `Я <shake>дрожу</shake>, <glitch=2>глючу</glitch> <gif=tenna>`.
* Редактор чата (U) → вкладка «Эффекты»: включение, скорость/сила, список эффектов (клик копирует тег), список GIF. В правилах 3-я строка — эффекты на всё сообщение.
* Эффекты совместимы с печатью (Undertale-режим) и любыми шрифтами.

## Текст на экране игроков (как Title, но со всеми функциями чата)

Любой текст можно показать на экране игроков: печать как в Undertale со звуками, эффекты, GIF, свои шрифты, якоря, анимации появления/затухания.
Настройки хранятся в **пресетах** — они лежат в папке мира (`fpstudio_screen_presets.json`) и едут вместе с картой.
Встроенные пресеты: `default` (по центру), `subtitle` (снизу, с печатью), `horror` (глитч), `undertale` (чёрная рамка + печать).

* **Редактор:** клавиша **Y** (или `/fpscreen edit [пресет]`, или клиентская `/fpscreeneditor`). Это тот же редактор, что у чата (позиция, якоря, вид, шрифт, печать, эффекты, анимации, иконки/GIF),
  плюс вкладка «Экран»: список пресетов, новый/копия/удалить, вертикальный центр, выравнивание текста, эффекты на весь текст, проба и «Показать всем».
  Нужны права оператора или креатив (в одиночке работает всегда).
* **Команды** (работают и из командных блоков):
```
/fpscreen show @a undertale 5 * Привет, <shake>путник</shake>!     # 5 секунд (-1 = время из пресета)
/fpscreen show @p horror -1 &cОн <glitch=2>рядом</glitch> <gif=eyes,24>
/fpscreen clear @a [пресет]
/fpscreen list
```
  Коды цвета `&c`, теги эффектов и `<gif=имя>` работают так же, как в чате. Один пресет = один «канал»: новое сообщение с тем же пресетом заменяет прежнее.
* **Скрипты НПС:** `screen <пресет> <секунды|-1> <текст>` и `screenclear [пресет]` — показывается игрокам в радиусе реплик НПС.
